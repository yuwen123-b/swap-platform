## 📖 项目介绍 (Introduction)
随着“双碳”目标的推进与社区经济的兴起，社区闲置物品的流转成为践行低碳生活与邻里互助的重要方式。然而，现有的二手交易产品普遍存在重商业化轻社区信任的问题：传统的发布模式需要繁琐的填表与议价，且静态图文极易导致“货不对板”；社区微信群信息碎片化严重，匹配效率低下。此外，现有平台普遍缺乏适老化与无障碍设计，将大量老年人与行动不便的特殊群体拒之门外，导致社区大量闲置资产难以被有效盘活。
针对上述痛点，本项目研发了**「闲物焕新」**——一个基于大模型技术的社区旧物互换与积分生态智能平台。
*   **核心AI技术**：深度接入多模态大模型实现“拍照即发布与智能定价”；创新引入图生 3D 重建与 360° 展示；智能体助手采用“意图分流 + Function-Calling”架构，通过 **MCP 协议**无缝集成高德地图与图表能力；集成语音 ASR/TTS 技术打造助老模式，消除数字鸿沟。
*   **商业闭环**：打通了“旧物回收-积分获取-商家兑换”的完整商业闭环。
*   **工程保障**：底层具备严密的并发防护逻辑与全站 AI 可靠性防护网，经 550+ 项自动化测试验证，具备极强的鲁棒性与高可用性。
**关键词**：旧物互换；智能体；FastAPI；Vue 3

## 🛠 技术架构 (Tech Stack)
*   **前端**：Vue 3 + Vite + Element Plus + Three.js (3D 渲染)
*   **后端**：Python 3.12 + FastAPI + Uvicorn
*   **数据库**：MySQL 8.0 (支持 SSL 加密与并发控制)
*   **AI 能力**：
    *   大语言/多模态模型：阿里云百炼 (Qwen/DeepSeek)、腾讯混元 3D、ModelScope
    *   智能体协议：MCP (Model Context Protocol) 集成高德地图与图表工具
*   **部署与运维**：Cloudflare Pages (前端边缘托管) + Docker 容器化 + Ngrok 穿透
