## 1. 商品封面现状：`MerchantProductGrid.vue`

### 1.1 组件链路

```
src/views/ItemList.vue                       ← 「探索物品」页，el-tabs
  └─ <el-tab-pane name="new" lazy>           ← 「新」Tab（积分兑换）
       └─ <MerchantProductGrid />            ← src/components/MerchantProductGrid.vue
            └─ <BrandThumb size="banner" />  ← src/components/BrandThumb.vue（共用封面组件）
```

`MerchantProductGrid` 自己**不画封面**，它把封面完全委托给 `BrandThumb`：

```vue
<!-- MerchantProductGrid.vue:46-56 -->
<div class="mpg-thumb">
  <BrandThumb
    :src="good.image"      <!-- product.image_url，实测 10/10 为 NULL -->
    :name="good.title"     <!-- 商品标题，决定「大汉字」 -->
    :seed="good.tier"      <!-- 0/1/2 价位档，决定渐变配色 -->
    :emoji="good.icon"     <!-- 店铺分类 emoji，决定右下角标 -->
    size="banner"
  />
</div>
```

```js
// MerchantProductGrid.vue:113-146 —— 封面三个输入量的来源
const CATEGORY_ICONS = { 打印:'🖨️', 便利店:'🏪', 理发:'💇', 回收:'♻️', 家政:'🧹' }
icon:  categoryIcon(shop.category),      // ← 按【店铺分类】给 emoji（同店必同）
image: product.image_url || '',          // ← 实测全 NULL → 永远走占位
tier:  priceTier(points),                // ← 50→0 / 200→1 / >200→2，只有 3 档
```

### 1.2 `BrandThumb` 占位分支到底画了什么

`BrandThumb.vue` 的优先级是「真图优先，失败/为空 → 品牌化占位」：

```vue
<!-- BrandThumb.vue:16-22 -->
<img v-if="showImage" :src="src" @error="onError" />
<template v-else>
  <span class="bt-text">{{ initial }}</span>        <!-- 名称首字，banner 档 56px -->
  <span v-if="emoji" class="bt-emoji">{{ emoji }}</span>  <!-- 白底圆点小角标 -->
</template>
```

- `initial = (name||'').trim().charAt(0) || '闲'` → **商品标题第一个字**（"打印券10张" → "打"）
- 渐变来自 `PALETTES[n % 6]`，`n = seed = tier`（0/1/2）→ 落在 `PALETTES` 的**前三位浅绿/中绿/深绿**
- 所以「同一家店视觉几乎一样」的根因有两个：
  1. **emoji 按店铺分类给** → 同一家店的所有商品 emoji 完全相同；
  2. **渐变只有 3 档价位，且与商品分类无关** → 同价位商品跨店也是同一个绿。

## 2. 商家列表封面现状：`MerchantList.vue`

```vue
<!-- MerchantList.vue:58-66 -->
<span class="shop-logo">
  <BrandThumb
    :src="shop.logo_url || ''"     <!-- 实测 5/5 为 NULL → 永远占位 -->
    :name="shop.name"              <!-- 商家名 → 首字大字（md 档 28px） -->
    :seed="shop.id"                <!-- 商家 id → 6 色绿/青渐变 -->
    :emoji="categoryIcon(shop.category)"
    size="md"
  />
</span>
```

- 容器 `.shop-logo` = 64×64、圆角 14px、1px 描边；
- 主视觉同样是**首字大字**（"社区打印店"→"社"、"24小时便利店"→"2"、"美发工作室"→"美"、"绿源回收站"→"绿"、"家政服务站"→"家"）；
- **`seed = shop.id`**（≠ 商品那套价位档）→ 取 `PALETTES[1..5]`，5 家店恰好错开 5 种绿/青渐变；
- emoji 仍只是右下角**小角标**。

> ⚠️ **与任务书描述的落差**：任务书写「现在：分类 emoji（🏪 🖨️ 💇）」。
> 实际 emoji 只是 20px 的角标，**主视觉是首字大字**。所以「改成分类图标 + 分类渐变色 + 商家名首字」
> 中间那条「商家名首字」**是现状已有的**，真正的增量是：emoji 角标 → **分类线性图标** + 按 id 的绿渐变 → **按分类的渐变**。

`MerchantDetail.vue`（店铺详情页）的店铺封面写法与 MerchantList **完全同构**（`:seed="merchant.id"`、`size="lg"`），
改动 MerchantList 时若只改一处，两页会出现风格分叉 —— 建议同批处理（见 §6 待确认 Q2）。

## 4. 任务书方案 vs 现状：6 处落差与建议

### 落差 ①（技术必改）`<img :src="iconUrl">` 无法用 CSS 控制颜色

任务书要求：*「图标风格：线性，stroke-width=2，**颜色由 CSS 控制**」* + 交付项 *「高对比度下图标清晰」*。
但任务书的 markup 草案是：

```html
<img :src="iconUrl" class="cover-icon" />
```

**外部 SVG 通过 `<img>` 引入后是一个封闭的栅格化结果**，其内部 `stroke="currentColor"` 不会继承外层 CSS 的 `color`，
也无法被 `html.theme-high-contrast` 覆盖 —— 想改色只能上 `filter`，既不准也不可读。

**建议**：仍把 SVG 落成静态文件（满足「图标用 SVG 静态文件」），但用 Vite 原生 **raw 内联**：

```js
const modules = import.meta.glob('../assets/icons/**/*.svg', { query: '?raw', import: 'default', eager: true })
```

拿到 SVG 源码后用 `v-html` 渲染。Tabler 图标本来就是 `stroke="currentColor"`，因此：

```css
.product-cover { color: #ffffff; }                       /* 白图标 */
html.theme-high-contrast .product-cover { color: #ffffff; background: #000 !important; }
```

一行 CSS 主题变量即可换色，**零新依赖**、零运行时成本（图标总大小 < 8 KB）。

### 落差 ②（内容缺口）映射表漏了家政 2 条商品

任务书 `PRODUCT_ICONS` 只覆盖 8 条，实测 10 条商品里 **「保洁1小时」「家电清洗」无映射** → 会落到兜底 `package.svg`。

**建议补 2 条**（Tabler 有现成线性图标）：

| 商品子串 | 拟用文件 | Tabler 源图标 |
|---|---|---|
| `保洁` | `cleaning.svg` | `spray`（清洁喷雾） |
| `家电清洗` | `appliance-clean.svg` | `wash-machine`（洗衣机/家电清洗） |

### 落差 ③（表述纠正）MerchantList 现状不是「分类 emoji」做主视觉

见 §2 注：emoji 只是角标，主视觉是首字。故「改造后 = 分类图标 + 分类渐变色 + 商家名首字」中，
**「商家名首字」保持不变**，真正改的是「角标 emoji → 分类线性图标」+「id 取色 → 分类取色」。

### 落差 ④（一致性风险）商品封面有 3 处复用点

| 位置 | 组件 | 现状 |
|---|---|---|
| 新Tab（本次主目标） | `MerchantProductGrid.vue` | `BrandThumb size="banner"`（168px 高）|
| 店铺详情页商品列表 | `MerchantDetail.vue` | `BrandThumb size="md"`（64×64）|
| 兑换确认弹窗 | `RedeemConfirmDialog.vue` | `BrandThumb size="md"`（64×64）|

只改新Tab → 同一个「旧衣回收抵扣券」在新Tab 是**渐变+图标**、在店铺详情页仍是**「旧」+♻️**，一眼看出是两个版本。
**建议**：抽 `ProductCover.vue` 一个组件，三处统一替换（任务书本身也允许「或新组件 ProductCover.vue」）。

### 落差 ⑤（同店可区分度）理发店 2 商品的图标不能太像

「基础理发券」与「洗剪吹套餐」同店、同紫渐变，全靠图标区分。
Tabler 的 `scissors` 与 `cut` 都是剪子剪影，**辨识度不足**。建议：

- `基础理发券` → `scissors`（闭合剪）
- `洗剪吹套餐` → `razor`（理发工具，竖长形体，与剪子轮廓差异明显）

### 落差 ⑥（同店仍同渐变）分类渐变是「同店同色」

按任务书「渐变 = 分类」，同店商品必然同渐变（理发店两件全紫、回收站两件全绿）。
可区分度完全依赖图标 —— 这**可以接受**（图标已足够区分），但若想更「产品化」，可在同分类内做一个
**由商品 id/title 派生的 0–12% 明度微扰**，让同店两件有轻微深浅差。
**默认建议：不做**（保持任务书口径、视觉更整齐）；如需再做，改一行即可。→ 列入 Q4。

> 即封面 = 分类渐变底 + **分类图标作主视觉** + **商家名首字**（叠在图标上或做成角标）。

## 8. 风险与约束复核

| 约束（任务书） | 复核结论 |
|---|---|
| 图标用 SVG 静态文件，不引图标库依赖 | ✅ 静态文件 + `import.meta.glob`，`package.json` 零改动 |
