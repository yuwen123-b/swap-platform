## 四、pytest 新增用例（26 例）

**`tests/test_item_exchange_mode.py`（16）**
1. 免费送发布：mode=1、price=0.00、expected_item=NULL
2. 交换发布：mode=2、即使传 price 也归 0、expected_item 落库
3. 低价转让发布：mode=3、price=88.50（量化 2 位）
4. 成色 / 原价写入：condition_level=4、original_price=1200.00
5. 低价转让不填价 → 400（且校验在落库前，零 SQL）
6-9. 价格越界参数化：`0` / `-5` / `100000` / `abc` → 400（中文提示）
10. 边界值 `0.01` 与 `99999` 均通过
11. 非法 exchange_mode=9 → 400
12. 非法 condition_level=6 → 400
13. 免费送 / 交换详情 price 归 0（即使库里有脏值 50）
14. 低价转让详情 price 透出 88.5
15. exchange_mode 为 None → 回落 1，不 500

**`tests/test_order_price.py`（10）**
- 低价转让下单 → INSERT 含 `price` 列、`value=88.50`、`exchange_type=1`
- 免费送下单 → 列清单**无** `price`、`exchange_type=3`
- 交换下单 → 列清单**无** `price`、`exchange_type=2`
- `resolve_order_price` 健壮性参数化 7 例（None/""/0/-3/abc/12.345/Decimal）
- 非购买单恒为 0（忽略物品价）

## 八、分类映射策略（不猜、不默认、不 fallback）

估价 `item_category` 是中文名 → 发布需 `category_id` 数字：
- 用已加载的分类表按 `name` 精确匹配，命中即用其 id；
- 未命中 → `category_id` **留空** + 提示「分类「XX」无法自动匹配，请手动选择」；
- 提交时若分类为空会被前端拦下（「请填写物品名称、描述、分类和联系方式」）。
