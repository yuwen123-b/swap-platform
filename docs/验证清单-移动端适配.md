## 四、已知限制与后续可选

| 项 | 说明 |
|---|---|
| 360° 双指缩放未真机验证 | CDP 的 `setTouchEmulationEnabled` 只能模拟单指点击，**捏合手势必须真机验证**（本文第五节有步骤） |
| 双击回正在 iOS | `touch-action:none` 已阻止浏览器双击缩放，`dblclick` 正常派发；若个别老 iOS 不派发，还有「重置视角」按钮兜底 |
| 分块体积 | 主 chunk 2.0MB（three.js 占大头）是历史现状，本次未动；如需优化建议独立做 `manualChunks` |
| autoprefixer | 未新增依赖。Vite 不自带前缀，但项目关键属性（`backdrop-filter` 等）已手写 `-webkit-`；如需兼容 iOS 12 再执行 `npm i -D autoprefixer postcss` 并加 `postcss.config.js` |
| 商家工作台 | 独立 MerchantLayout 未适配（本任务范围外），手机访问 `/merchant/dashboard` 仍是 PC 样式 |

## 五、如何自测（F12 手机模式）

### 5.1 Chrome DevTools（1 分钟起）

1. Chrome 打开 `http://localhost:5173`（dev server 已在跑；或 `npm run preview` 用构建产物）。
2. `F12` 打开开发者工具 → `Ctrl + Shift + M`（或点左上角手机图标）进入**设备工具栏**。
3. 顶部下拉选 **Dimensions: Responsive**，手动拖成 **375 × 667**；DPR 选 2。也可直接选预设 **iPhone SE / iPhone 12 Pro**。
4. 按 `Ctrl + Shift + R` **强制刷新**（媒体查询和 viewport 变更必须重载页面才生效）。
5. 逐页过（对着下面的检查点打勾）：

| 页面 | 检查点 |
|---|---|
| `/` 首页 | 顶栏只有 Logo+私信+头像+「⋯」；分类宫格 4 列不挤；无横向滚动条 |
| `/items` | 底部 4 Tab；卡片 2 列；筛选区各控件独占一行；排序行可左右滑 |
| `/items/77` | 3D 区单列在上；提示文案是「单指拖动旋转 · 双指缩放」；控制条 3 个按钮一行 |
| `/assistant` | 输入框贴底可见；点输入框弹出软键盘后**输入框仍在可视区**（DevTools 里看 `--app-vvh` 变化） |
| `/merchant` | 商家卡片横向布局；筛选贴片可横滑且无滚动条 |
| `/profile` | 表单 label 在输入框上方；弹窗占 92vw |
| 任意页 | 底部 Tab 点击切换 + 高亮正确；页面无左右晃动 |

6. 打开 **Rendering 面板**（`Ctrl+Shift+P` → 输入 "Show Rendering"）→ 勾选 **Paint flashing** 与 **Layout Shift Regions**，滚动页面：不应出现大面积绿色重绘或蓝色布局偏移。
7. 回归 PC：把 Responsive 宽度拖到 **768 以上**（或点掉设备工具栏），确认 7 项顶栏、4 列卡片、悬浮「首页」按钮全部回来——**768 是分界线，必须验**。

### 5.2 触摸与手势（DevTools 模拟不了捏合）

- 设备工具栏可模拟**单指**拖拽（按住拖动）→ 验证 3D 旋转、360° 旋转。
- **双指捏合 DevTools 不支持**，需要真机：`npm run dev` 后 dev server 监听 `0.0.0.0`，手机连**同一 Wi-Fi**，浏览器访问终端里的 `Network: http://192.168.x.x:5173`（后端 `/api` 已代理，无需额外配置）。
- 真机重点验证：① 360° 双指缩放（本次新增能力）；② iOS 键盘弹起后助手输入框是否被遮；③ 微信内置浏览器里打开一遍核心路径（微信 UA 下 `hover:none` 同样命中，Tab 栏应正常）。

### 5.3 常见假象排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 还是 PC 布局 | 没强刷 / viewport 被扩展改写 | `Ctrl+Shift+R`；DevTools → Rendering → 检查 viewport meta |
| 输入框聚焦页面变大 | 输入框字号 <16px | 本次已全局强制 16px，若某个输入框仍触发，检查是否有内联 `font-size` |
| 底部 Tab 挡住内容 | 页面根元素不是 `.page` | 个别自定义页需自查 `padding-bottom` |
