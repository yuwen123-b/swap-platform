## 4. 实现要点（对任务书草案的 3 处技术落实）

1. **Q1 raw 内联**：`import.meta.glob('../assets/icons/**/*.svg', { query: '?raw', import: 'default', eager: true })`
   构建期内联 SVG 源码，`ProductCover` 用 `v-html` 渲染；Tabler 原生 `stroke="currentColor"`，
   于是「图标颜色由 CSS 控制」成立（高对比度把渐变压黑 + 图标白 + 描边 2.6，一行 CSS 搞定）。
   构建产物中 **0 个独立 .svg 文件**、14/14 路径内联进 JS。
2. **圆角交给父容器**：封面根元素用 `border-radius: inherit` 而非草案的 `12px 12px 0 0`。
   原因：封面外层卡片已是 16px 圆角 + `overflow:hidden`，再叠一个更小的 12px 会在左/右边缘
   （y≈12–16px 处）露出浅色缺口（几何上 16px 圆弧并不完全包含 12px 圆弧）。
3. **hover 归属调用方**：图标 hover 放大写在 3 个使用方的 `:deep()` 规则里
   （组件内部不写 self-hover，避免与调用方规则同特异性时胜负取决于样式注入顺序）。
   卡片整体上浮/阴影沿用各页既有规则。
