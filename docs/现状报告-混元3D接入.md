## 二、六个必答问题（全部有官方文档/实测依据）

### Q1 用哪个 Python SDK？包名？

**不需要任何 SDK。** 这是最重要的发现：

| 接入路径 | 鉴权 | SDK | 版本 |
|---|---|---|---|
| **TokenHub 网关（Express 所在）** | `Authorization: Bearer <API Key>`（sk- 开头） | **无官方 Python SDK，直接 requests** | 文档 product **1823** |
| 老混元生3D API（专业版） | SecretId + SecretKey（TC3-HMAC-SHA256 签名） | `tencentcloud-sdk-python` | `hunyuan.tencentcloudapi.com`，Version 2023-09-01 |

Express（hy-3d-express）**只在 TokenHub 网关**，不在 TC3 签名那套 API 里。`tencentcloud-sdk-python` 用不上——这正好满足你"不引入付费依赖"的约束（requests 项目已有）。

### Q2 调用接口的完整路径

```
提交：POST https://tokenhub.tencentmaas.com/v1/api/3d/submit
查询：POST https://tokenhub.tencentmaas.com/v1/api/3d/query
头：  Authorization: Bearer <API Key>  +  Content-Type: application/json
```

**域名实测**（重要）：
- `tokenhub.tencentmaas.com`（官方文档域）→ **可达**。不带 Key 401；带你的 Key + 假任务 id 返回 `{"status":"failed","error":{"code":"FailedOperation.JobNotFound","message":"任务不存在。"}}` —— **你的 Key 鉴权通过**
- 截图里的 `tokenhub.tencentsaas.com` → **本机 DNS 解析失败**（curl exit 7）。以文档域 `tencentmaas.com` 为准，实现时做成可配置

### Q3 同步还是异步？轮询间隔？

**异步任务**：
- 提交即返回 `{id, request_id, status}`，status ∈ `queued / in_progress / completed / failed`；**任务 id 有效期 24 小时**
- Express 官方口径**生成时间 ≤1 分 30 秒**
- **默认并发 1**：上一个任务没完成，无法提交下一个（Express 专属限制，专业版才是 3 并发）
- 文档未规定轮询间隔 → 建议实现：**5 秒间隔 + 300 秒上限**（6 倍余量覆盖 90s 官方口径）

### Q4 输入图片：本地 base64 还是公网 URL？

**两者都支持，用 base64（推荐）**：

| 参数 | 限制 |
|---|---|
| `image_base64` | **≤6MB**，jpg/png/jpeg/webp，单边 128~5000 |
| `image_url` | ≤8MB，同格式 |
| `prompt` | 文生3D（与图互斥，**图和 prompt 不能同时传**） |

→ 走 base64 后 **`PUBLIC_BASE_URL` / ngrok 隧道不再是 3D 的前置依赖**（现有 `ensure_local_jpeg()` 直接复用，产出本地 JPEG → base64）。

### Q5 输出：GLB 的 URL 还是 base64？

**返回 URL，不是 base64**。查询成功后 `data` 是数组，每项 `{type, url, preview_image_url}`：

- `result_format` 可选 `obj / glb / stl / usdz / fbx / mp4`，**默认返回 obj 格式组** → **必须显式传 `result_format: "glb"`**，否则拿到的是 OBJ（前端 ModelViewer 加载不了）
- `url` 是带 `q-signature` 的 **COS 签名地址（有效期 24h）** → 必须提交成功后**立即下载落盘**——现有 `_download_model` 的"先写 .part 再 replace"逻辑直接复用

### Q6 免费额度？积分怎么算钱？

| 项 | 数值（官方文档） |
|---|---|
| 积分换算 | **1 积分 = 0.12 元**（后付费，日结） |
| Express 单次消耗 | **15~25 积分/次 = 1.8~3 元/次**（文生/图生 15 分；开 PBR +10 分） |
| 失败计费 | **不计费**（任何失败，包括风控拦截） |
| **免费额度** | 新人体验包：3D 生成 **100 积分**（≈¥12 ≈ **Express 4~6 次**），活动截至 2026-12-31，额度有效期 1 年 |
| 领取方式 | TokenHub 控制台 → 模型广场 → "新用户福利"，或首次调用自动领取 |
| 免费额度用尽后 | 不自动转后付费，需在控制台开启；未开启则 API 报欠费错误 |

对比：Tripo H3.1 实测 2.1 元/次 —— **价格基本持平，混元略便宜，且国内直连稳定、无每日配额**。

## 四、任务书与实际的 5 处差异

| # | 任务书 | 实际 | 处理 |
|---|---|---|---|
| **C1** | 参考文档 product **1729** | 1729 是**混元大模型（LLM）**文档；3D 在 **product 1823**（TokenHub） | 按 1823 实现 |
