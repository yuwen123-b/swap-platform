## 三、实际调用的模型（代码链路 + 今日实测复现）

`panorama_service.generate()` → `llm_client.image_edit()` 的三层链路，逐层实测：

1. **魔搭** `Qwen/Qwen-Image-Edit-2511`（`IMAGE_PROVIDER=modelscope`，OpenAI 兼容
   `/v1/images/edits`）→ **404 page not found**（0.6s，复现第 10 批结论，该端点在
   api-inference 上不存在）；
2. **百炼** `wanx2.1-imageedit`（异步任务 REST）→ 立即抛错「需要公网可达的图片 URL」
   （`PUBLIC_BASE_URL` 为空）；
3. **降级文生图**（panorama_service.py:146-152）：`describe_image`（qwen3-omni-flash
   VL 描述）+ `text_to_image`（wanx2.1-t2i-turbo 重画）。

**→ 实际生效的只有第 3 层。这就是"4 张图不是同一物品"的直接原因：模型根本没见过原图，
只拿到一段 80 字的文字描述。**

### 当前 prompt 全文

- 编辑链路（实际未生效）：
  - left：`同一物品的左侧90度视角照片，外观、颜色、材质保持一致，背景简洁`
  - back / right 同构，一句话、无任何强约束。

  —— VL 描述丢掉了原图的精确外观，t2i 自由发挥 → 幻觉文字、款式漂移。

## 四、决定性实验（3 组探针，原图 = item 73 front）

| 探针 | 结果 | 判定 |
|---|---|---|
| ① `wanx2.1-imageedit` + **base64 直连**（绕过 PUBLIC_BASE_URL） | ✅ 成功，19.8s | 但输出与原图**几乎同一视角**（仅轻微重绘，logo 画花）→ 复确认：该模型 10 种 function 均不含视角旋转，**修通它没有意义** |
| ② `qwen-image-edit` / `-plus` / `-max` | ❌ Model not exist | 当前账号/区域不可用 |
| ③ **`qwen-image-2.0-pro`**（multimodal-generation 端点 + base64 + 6 条严格视角 prompt） | ✅ 成功，**19.0s** | **真正完成了视角旋转**：同一奶油白沙发（同色、同贵妃位、同橙色踢脚装饰、同扶手形态）从背面 3/4 角度重绘，物体同一性保持很好。不足：转角比"正左 90°"略过头、背景从纯白变灰白影棚 → 属于 prompt 可调问题，不是能力问题 |

## 五、修复路线建议（等确认后执行）

**模型**：`qwen-image-2.0-pro`，走 DashScope `multimodal-generation/generation` 同步端点，
图像传 **base64 data URL**（官方文档明确支持，**不需要 PUBLIC_BASE_URL**），
复用现有 `requests`，**零新依赖**。官方能力清单明确含 novel view synthesis / 物体旋转。

1. `llm_client` 新增 `_image_edit_qwen(image_path, prompt)`：PIL 规整为 JPEG → base64 →
   同步 POST → 提取 `output.choices[0].message.content[].image` → 下载字节；
   `.env` 的 `LLM_IMAGE_EDIT_MODEL` 改为 `qwen-image-2.0-pro`，编辑端点 URL 相应调整；
2. **删除文生图降级分支**（panorama_service.py:145-152）：编辑失败 → `panorama_status='failed'`，
   前端已有静态图降级展示（宁可失败，不要乱画）；
3. prompt 换成你提供的 6 条严格版（left/back/right 三个变体）；
4. 魔搭 404 分支保留不动（不重构无关代码）。

### 成本与耗时
- 定价：qwen-image-edit 系 0.3 元/张（北京区域，控制台价为准）→ 3 张/物品 ≈ **0.9 元/物品**；
- 单张 ~19s → 3 张 ≈ 60s/物品，BackgroundTasks 异步执行（现有 10 分钟卡死兜底覆盖）；
- 输出 PNG ~950KB/张，由现有 `_compress_views` 压到 ≤500KB。

用 3 个真实物品（杯子 / 书 / 椅子）走完整生成流程，4 张图存临时目录供人工比对，
报告耗时 + 主观一致性评价。效果可接受 → 继续深度视差；不可接受 → 走情况 D 隐藏入口。
